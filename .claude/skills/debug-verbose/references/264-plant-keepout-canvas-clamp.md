# Case study: a plant that could not touch the fence (spacing ring in the canvas clamp)

**Symptom.** On the Encanto plan the owner could not drag a plant right up to the fence at the plan's right edge; the agent could place them there. **Wrong theories.** A keep-out radius from species data, object snapping (10 cm), the constraint solver, bed containment, the gate/fence code: none exists in the move path (`grep` for keep-out/clearance finds only Agent API tools). **Key log line.** With `[STEP]` wrappers on each post-drag step of `mouseMoveEvent`, on a copy of the plan: `STEP _clamp_dragged_items_to_canvas (3815,1880) -> (3745.58,1880)` on every move while snapping was off. **Root cause.** The clamp used `sceneBoundingRect()`, which includes the spacing ring. **Lesson.** Instrument each step of a multi-stage handler and print before/after per step; when an unexplained push appears, look for paint bounds standing in for geometry (#841). Reproduce on a copy of the user's real plan, not on a synthetic scene: the synthetic scene had no plant near the plan edge and passed.
